# 📱 YouniFirst: Platform Kemahasiswaan Terintegrasi Berbasis Mobile dan Website untuk Mendukung Ekosistem Informasi dan Kolaborasi di Politeknik Negeri Jember

## Aplikasi Mobile — Untuk Mahasiswa POLIJE

**YouniFirst Mobile** adalah aplikasi mobile yang dirancang khusus untuk mahasiswa POLIJE sebagai pengguna utama. Aplikasi ini membantu mahasiswa mengembangkan kemampuan, meningkatkan kolaborasi, serta mengakses seluruh informasi kampus dalam satu genggaman.

Dengan semangat **"Your First Step to Innovation and Synergy in Technology"**, YouniFirst menghadirkan pengalaman digital yang produktif, terhubung, dan efisien.

---

## 🎯 Target Pengguna

| Peran | Akses |
|-------|-------|
| **Mahasiswa** | Seluruh fitur aplikasi (Dashboard, Event, Team, Lost and Found, Profil) |

> ⚠️ **Catatan:** Aplikasi mobile ini **khusus untuk mahasiswa**. Admin dan Satpam menggunakan website terpisah.

---

## 📱 Fitur Aplikasi Mobile

### 1️⃣ Dashboard
Halaman utama yang menampilkan ringkasan informasi untuk mahasiswa.

| Fitur | Fungsi |
|-------|--------|
| **Selamat Datang** | Menampilkan nama pengguna yang sedang login |
| **Statistik Singkat** | Jumlah event terbaru, tim aktif, laporan lost and found |
| **Akses Cepat** | Tombol pintas menuju Event, Team, dan Lost and Found |
| **Notifikasi** | Menampilkan pengumuman terbaru dari admin |

---

### 2️⃣ Event
Semua acara kampus dikumpulkan dalam satu tempat.

| Fitur | Fungsi |
|-------|--------|
| **Lihat Event** | Melihat daftar event terbaru dan yang sedang populer |
| **Detail Event** | Melihat detail lengkap event (tanggal, tempat, deskripsi, kuota) |
| **Daftar Event** | Mendaftar seminar, workshop, webinar, turnamen, konser, dan event lainnya |
| **Riwayat Pendaftaran** | Melihat event yang sudah didaftarkan |
| **Bagikan** | Membagikan event ke mahasiswa lain |

---

### 3️⃣ Team
Fitur untuk membentuk atau bergabung dengan tim kompetisi.

| Fitur | Fungsi |
|-------|--------|
| **Lihat Perekrutan** | Melihat daftar posting perekrutan tim yang tersedia |
| **Detail Perekrutan** | Melihat role yang dibutuhkan, kriteria, dan detail lomba |
| **Buat Perekrutan** | Ketua tim membuat posting perekrutan tim baru |
| **Ajukan Diri** | Mahasiswa mengajukan diri untuk bergabung ke tim |
| **Tim Saya** | Melihat tim yang diikuti atau dibuat |
| **Kelola Tim** | Mengedit atau menghapus posting perekrutan (untuk ketua tim) |

**Alur Fitur Team:**
1. Ketua tim membuat posting perekrutan berisi role, kriteria, dan detail lomba
2. Mahasiswa lain membaca postingan dan mengajukan diri
3. Ketua tim meninjau kandidat melalui link form atau kontak
4. Anggota baru diterima dan mulai bekerja sama

---

### 4️⃣ Lost and Found
Solusi cepat untuk laporan barang hilang atau ditemukan di lingkungan kampus.

| Fitur | Fungsi |
|-------|--------|
| **Buat Laporan** | Membuat laporan barang hilang/temuan dengan foto, lokasi, dan detail kejadian |
| **Lihat Laporan** | Melihat daftar barang hilang/temuan terbaru |
| **Detail Laporan** | Melihat informasi lengkap laporan |
| **Status Laporan** | Mengecek status penanganan laporan |
| **Hubungi** | Menghubungi pemilik atau penemu melalui kontak yang disediakan |
| **Riwayat Laporan** | Melihat laporan yang pernah dibuat |

> 🔗 Terintegrasi dengan panel Satpam untuk penanganan lebih cepat.

---

### 5️⃣ Profil
Halaman untuk mengelola informasi akun mahasiswa.

| Fitur | Fungsi |
|-------|--------|
| **Informasi Pribadi** | Melihat dan mengedit data diri (nama, NIM, jurusan, nomor telepon, email) |
| **Ubah Password** | Mengganti password akun |
| **Foto Profil** | Mengunggah dan mengganti foto profil |
| **Riwayat Aktivitas** | Melihat riwayat pendaftaran event, tim yang diikuti, dan laporan lost and found |
| **Pengaturan Notifikasi** | Mengatur notifikasi yang ingin diterima |
| **Logout** | Keluar dari aplikasi |

---
